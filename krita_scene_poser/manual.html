KSP — Krita Scene Poser

Version 0.0.8 — early development build. Pose the Body-chan or Body-kun figure in the docker or directly on the canvas, reshape its body, import your own rigged figures, save and reload poses, and create a transparent line-art layer or shaded guide layer from the result. Compatibility is verified only on Krita 5.3.3 for Windows.

Pose a figure

Choose a figure at the top of the docker; switching keeps the pose. Click a body part to select it; the hint line explains what dragging it does.

  • Drag mode: drag a limb to swing it. Drag a hand or foot to place it (the arm or leg follows). Shift+drag twists; Ctrl+drag rotates a hand or foot itself. Drag the hips to move the figure; Shift+drag the hips to turn it.
  • Rings mode (Rings button or T): click a part, then drag a ring. Red and blue bend the joint; green twists it along the bone.
  • View: right-drag or Alt+drag orbits, middle-drag or Alt+Shift+drag pans, the wheel zooms, F frames, O toggles orthographic.
  • Edits: Esc cancels a drag; Ctrl+Z and Ctrl+Shift+Z undo and redo poses while the viewport has focus; R resets the selected joint. Buttons reset or mirror the pose and copy a limb to the other side.
  • Joint limits (Pose tab, on by default): elbows and knees cannot bend backwards, and other joints keep to a plausible range. The hint line says when a joint is against a stop. Dragging a hand or foot may stop short of the cursor because a real limb would. Turn limits off for exaggerated poses.
  • Figure opacity (Pose tab) fades the figure in the viewport, on the canvas, and in the guide layer.

Body shape

The Shape tab has fifteen sliders. Proportions: height, head size, neck length, torso length, arm length, leg length, hand size, foot size, and shoulder width. Build: chest, waist, hips, arm thickness, leg thickness, and overall build. Each slider is a percentage of the figure's own size.

The body rebuilds about a quarter of a second after you stop dragging a slider. Your pose, camera and undo history are kept, and the figure stays on the ground. Reset Shape returns every slider to 100 %. A scene file stores the shape. Shape is a property of the figure, so it is not part of the pose undo.

Poses and scenes

The Scene tab holds nine bundled poses: choose one and press Apply Pose, which is a single undo step. Save Pose… and Load Pose… store just the pose, keyed by joint name, so a pose saved on one figure suits the other. Save Scene… and Load Scene… also keep the camera, view mode, line-art settings, opacities, and output size. KSP restores your last pose and settings when the docker opens again; that is kept with Krita's settings, not in your document.

Pose on the canvas

Show on Canvas (Pose tab) draws the figure on the canvas where the Create buttons would place it; it follows canvas zoom, rotation, mirror, and pan. Pose on Canvas (or Tools → Scripts → KSP: Pose on Canvas) works like an object tool: drag the figure to pose it, drag empty space to orbit (Shift pans, Ctrl moves closer). The wheel, middle-drag, Space, and the right-click palette still control the canvas. Brushes are paused until you turn it off. If a Krita update changes its canvas internals, canvas posing turns itself off and the docker keeps working.

Line art

The View switch above the viewport chooses Shaded, Lines, or Both, in the docker and on the canvas. The Line Art tab turns line types on or off: Outline (the silhouette), Contours (one part in front of another), Creases (sharp folds), and Seams (the mannequin's segment lines). It also sets the outline and inner widths in document pixels, the crease angle (lower finds more), the contour sensitivity (higher finds smaller overlaps), and the line color. Settings are remembered. Changing one while in the Shaded view switches to Both so you see the effect.

The canvas preview shows the exact line weight of the layer; the docker viewport shows widths in screen pixels.

Create layers

In the Output tab, Create Lineart Layer adds a transparent "KSP Lineart" paint layer and Create Guide Layer adds a transparent "KSP Figure Guide" layer with the shaded figure, both rendered from the current view.

The same tab sets the output: the document's size or a custom size placed centered or at the top left (pixels outside the canvas stay in the layer), a quality of 1×, 2× or 4× that renders larger and scales down for smoother edges, and the opacity of the layer KSP creates. Update the layer I made last rewrites your previous KSP layer in this document instead of adding another; if it is gone or you renamed it, KSP leaves it alone and creates a new one.

Your own models

In the Scene tab, Import Figure… adds your own rigged figure from a .glb, .vrm or .blend file. Bone names from Rigify, Mixamo, VRM and Blender's metarig are recognized; any other rig needs a small <model>.ksp-map.json file beside the model. Save .blend files with Compress turned off.

KSP turns the figure upright and forward, stands it on the ground, keeps its size unless that size is implausible, and reports what it matched. Imported figures join the figure list and are stored in Krita's application-data folder; your original file is never changed. The repository's docs/custom-figures.md has the details.

Open KSP

Enable KSP in Settings → Configure Krita → Python Plugin Manager, restart Krita, then open Settings → Dockers → KSP — Krita Scene Poser.

Check the GPU path

Press Self-Test to render a color test pattern offscreen and check channel order, orientation, and transparency. It adds nothing to the document.

Documents

Export creates a fresh layer. The prototype only supports RGBA/U8 documents with an sRGB profile: sRGB-elle-V2-srgbtrc.icc (Krita's default for new documents), sRGB-elle-V4-srgbtrc.icc, or sRGB built-in (what Krita gives images opened without an embedded profile). Other formats, including linear sRGB, are rejected instead of being converted; use Image → Convert Image Color Space if needed. A size guard limits memory use.

Menu actions and shortcuts

Tools → Scripts contains KSP: Show Scene Poser, KSP: Create Guide Layer, KSP: Create Lineart Layer, KSP: Save Pose…, KSP: Load Pose…, KSP: Pose on Canvas, and KSP: Diagnostic Log. They have no default shortcuts, so they never clash with Krita's. To assign keys, open Settings → Configure Krita → Keyboard Shortcuts and search for "KSP".

Diagnostic log

The log is off by default. When KSP: Diagnostic Log is checked, KSP writes events to krita_scene_poser/logs/ksp.log in Krita's resource folder (Settings → Manage Resources → Open Resource Folder). The log records GPU strings, sizes, and timings. It never records file paths, document names, or pixels, and nothing is sent anywhere.

Troubleshooting

Use Copy Diagnostics in the docker when reporting missing modules, context errors, shader failures, or export errors. The report holds versions and GPU details only, with no file paths or document names, and nothing is sent automatically. A successful viewport alone does not verify channel order, alpha, canvas transfer, or the full docker lifecycle.

KSP works with Krita's default Windows renderer (ANGLE/Direct3D) and with desktop OpenGL, so no display setting needs changing. On laptops with two GPUs, the diagnostics renderer line shows which one Krita is using.

KSP uses only Krita's bundled Python, PyQt5, and the standard library. Do not install PyOpenGL, NumPy, Blender, or an external helper to work around an unsupported Qt build.

Disable or uninstall

Uncheck KSP in Python Plugin Manager and restart to disable it. To uninstall, close Krita and remove only krita_scene_poser.desktop and the krita_scene_poser directory from Krita's resource pykrita folder. Existing exported paint layers remain in their documents.
